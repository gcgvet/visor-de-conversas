# Visor de Conversas

Abra conversas exportadas do WhatsApp em um visor de celular no seu navegador. O aplicativo é um único arquivo HTML e dispensa instalação.

## Download

[Baixar visor-de-conversas.html](https://github.com/gcgvet/visor-de-conversas/blob/main/visor-de-conversas.html) · Na página do arquivo, clique em **Download raw file**. Salve com a extensão `.html` e abra o arquivo em um navegador atualizado, como Chrome ou Edge.

## Como usar

1. Exporte a conversa no WhatsApp. Inclua as mídias se quiser visualizá-las no visor.
2. No visor, clique em **Carregar conversa** e escolha o arquivo TXT ou ZIP. Se o ZIP contiver várias conversas, selecione uma delas.
3. Se os anexos estiverem separados, clique em **Selecionar pasta de anexos**. O visor vincula os arquivos disponíveis pelo nome.
4. Clique no anexo dentro da conversa para abrir a prévia de imagens, vídeos, áudios ou PDFs, conforme o suporte do navegador. Outros formatos ficam disponíveis para baixar.
5. Use **Mensagens à direita** para escolher o participante desse lado. Alterne entre **Modo escuro** e **Modo claro** e use **Gerar print em PNG** para salvar a área visível do visor.

6. Clique em **Escolher plano de fundo** para usar uma imagem do seu dispositivo. A imagem aparece também no print em PNG. Use **Restaurar fundo padrão** para remover a personalização. A escolha vale até fechar ou recarregar o visor.

## Privacidade e compatibilidade

Conversas e anexos são processados localmente no navegador. O aplicativo tenta consultar um [Gist público](https://gist.github.com/abdurrahmanekr/2747d704edec93a06e454eba2653e0) para carregar o plano de fundo. Quando o fundo externo está indisponível, o visor usa o padrão interno. Os emojis usam a fonte do sistema, então o desenho pode variar.

Projeto independente, sem vínculo com o WhatsApp ou a Meta.
